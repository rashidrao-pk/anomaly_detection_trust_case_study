# Paper figure reproduction guide

Reference: archived AD_VAE_GAN_SCREW.ipynb and results/screw on the xai-2024-paper branch.

This command creates paper-style regenerated figures, not guaranteed pixel-identical copies of notebook output. Never use a new-checkpoint plot as evidence of reproducing the archived checkpoint.

## Inventory

- Training curves (vae_loss, disc_loss, gen_los): notebook cells 18-21; supported from history CSV.
- GT_screw.png: cell 27; supported from MVTec images and ground-truth masks.
- samples_m_screw.png: cell 25; supported from checkpoint and training images.
- segmentation_lime_50.png and segmentation_lime_100.png: cell 38; not yet automated.
- anomaly_score_separation_max.png: cell 46; separate anomaly-score data/threshold needed, not yet automated.
- plt_screw_lime_S1.png and PDF: cell 51, blend_2 LIME; supported with experiment CSV and threshold.
- plt_screw_lime_S2.png and PDF: cell 54, blend_3 LIME; requires a CSV containing blend_3, not the archived blend_2 CSV.
- plt_screw_shap_S3.png and PDF: cell 56, blend_2 SHAP; supported with experiment CSV and threshold.
- imgs, imgs_screw_full.html, imgs_screw_full.pdf: cells 40, 42, 48; full heatmap/gallery regeneration not yet automated.

## Usage (run at repository root)

For a newly trained model:
    conda activate xai-ad
    python scripts/paper_figures.py --config configs/screw.yaml --kind curves
    python scripts/paper_figures.py --config configs/screw.yaml --kind gt
    python scripts/paper_figures.py --config configs/screw.yaml --kind samples

To use archived weights for the samples panel:
    python scripts/paper_figures.py --config configs/screw.yaml --kind samples --checkpoint models/screw_VAE_GAN_30000/screw_VAE_GAN_30000_model

To rebuild S1 from archived experiment records (replace THRESHOLD with numeric delta_opt from the notebook):
    python scripts/paper_figures.py --config configs/screw.yaml --kind s1 --results-csv "results/screw/testresults_320_100_30000_5000_screw_blend_2_['LIME_SHAP'].csv" --threshold THRESHOLD

For S3 change --kind s1 to --kind s3. For S2, supply a blend_3 CSV; do not relabel blend_2 results as blend_3.

Figures are written as PNG and PDF under outputs/screw/paper_figures by default. A vector PDF is generated by Matplotlib.

Caveats: The Jaccard scatter is rebuilt from provided archived per-image metrics rather than running LIME/SHAP again. Its threshold, samples, and dataset completeness determine whether it matches notebook figures. Notebook pixel alignment and full experiment parity remain unverified. For new model S1-S3, first generate per-image explanation/Jaccard experiment records for the new checkpoint; this is still outstanding.
