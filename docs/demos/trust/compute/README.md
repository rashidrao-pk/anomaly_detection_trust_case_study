# Interactive demo: inside the trust case study

A static page that replays the paper's pipeline, stage by stage, on the eight
samples of Fig. 3 and Fig. 4:

1. **Detect**: ξ, its VAE-GAN reconstruction ξ′, the anomaly map m and the score α = max(m), with linked pixel readouts and the pixel that sets α.
2. **Decide**: the paper's Fig. 2 for the whole test set, with a draggable threshold τ, the confusion matrix and the √(TPR·(1−FPR)) criterion that selects τ*.
3. **Explain**: the Quickshift superpixels (S1, and S2 which also sees γ), the logged LIME perturbations one by one, LIME's weights as the fit grows from 10 to 5000 perturbations, and the SHAP partition map.
4. **Verify**: γ′ = {β ≥ θ} against the ground truth γ with TP/FP/FN pixels, the Jaccard curve over θ and its maximum, next to the value in the archived paper run.

```
docs/demos/trust/
├── index.rst              # the Read the Docs page that embeds the demo
├── app/
│   ├── index.html         # the demo; also works on its own
│   └── assets/data.js     # generated by compute/pack.py
└── compute/
    ├── config.toml        # samples, budgets, MVTec AD path
    ├── explain.py         # runs the paper pipeline, logs LIME, writes out/*.npz
    └── pack.py            # out/ + archived CSVs + Fig. 2 PDFs -> app/assets/data.js
```

## Rebuild

```bash
pip install -r requirements.txt pymupdf scipy      # TF 2.15 needs Python 3.9–3.11
cd docs/demos/trust/compute
python explain.py --mvtec-root /path/to/MVTec     # ~3 min per sample on a laptop CPU
python pack.py                                    # writes ../app/assets/data.js
python pack.py --standalone trust_demo.html       # optional: one self-contained file
```

`pack.py` reads the archived results on the `xai-2024-paper` branch with
`git show`, so run it inside a clone that has fetched that branch.

`explain.py` starts one process per sample to keep memory under ~4 GB. The
fit shown after *n* perturbations is LIME's own ridge regression refitted on
the first *n* rows of the log; the script stops with an error if the fit on all
rows does not reproduce the explanation `explain_instance` returned.

### Without the dataset

`python explain.py --source archive` recovers each 128 px input and ground-truth
mask from the SVG figures archived on `xai-2024-paper`. Matplotlib stored them
upsampled to 248 px with its hanning filter, which is linear, so the script
inverts it with a regularised least-squares solve and re-quantises to 8 bits.
On the eight samples this reproduces the paper's anomaly scores to within 0.007,
and SHAP's best Jaccard index equals the archived value on six of the eight; the
LIME maxima move by a few hundredths, since Quickshift reacts to small pixel
changes. The page shows a "Preview data" banner for such builds.

## Publish

`conf.py` copies every `docs/demos/*/app/` folder into the built site, next to
the page that embeds it, so Read the Docs serves the demo with no extra step.
Inside the docs the page hides its own title and method notes (the `.rst` page
carries them), sizes the iframe to its content and follows Furo's light/dark
switch. Opened directly, `app/index.html` shows the full standalone page.
